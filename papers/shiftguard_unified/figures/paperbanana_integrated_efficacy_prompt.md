# PaperBanana plot brief: integrated efficacy confirmation

Use the aggregate data file [`integrated_efficacy_contrasts.csv`](integrated_efficacy_contrasts.csv), which is a verified presentation copy of the frozen primary contrasts in `outputs/shiftguard_unified/integrated_confirmation/efficacy_100_v1/analysis_v3/primary_contrasts.csv`.

Create one publication-style statistical **forest plot** with three vertically stacked facets, one per comparator: **Continue**, **Two-gate**, and **Fixed-candidate pipeline**. Plot the mean paired expected-utility difference for **Full pipeline minus comparator** on the horizontal axis; positive values favor the full pipeline. Put the eight synthetic profiles on the vertical axis, using the same order in each facet. Draw the supplied descriptive paired-seed bootstrap 95% intervals as horizontal lines and the mean as a point. Add a vertical zero reference line. Follow PaperBanana's [NeurIPS plot-style guide](https://github.com/dwzhu-pku/PaperBanana/blob/main/style_guides/neurips2025_plot_style_guide.md): white print-friendly canvas, muted accessible colors paired with distinct geometric markers, light dotted grid behind the data, sans-serif labels, and direct labeling. Do not use decorative icons or invent data.

The figure must preserve all 22 rows exactly. Do not omit, pool, smooth, or reweight contrasts. The source family contains 22 predeclared one-sided tests adjusted by Holm at familywise 0.05; the plotted bootstrap intervals are **descriptive and not multiplicity-adjusted**. Do not visually imply those intervals are simultaneous or that a confidence interval crossing zero is the registered significance test. If labeling significance, use the supplied `holm_adjusted_p`/`holm_reject_at_0_05` fields, and distinguish the Bonferroni simultaneous lower bound from the plotted interval. Keep exact-zero contrasts at zero.

Caption: “Integrated synthetic efficacy confirmation (100 independent streams per profile). Each point is the mean paired expected-utility difference of the full monitor–scout–certify–intervene pipeline relative to the named baseline; positive values favor the full pipeline. Bars show descriptive paired-seed bootstrap 95% intervals. The registered 22 one-sided contrasts use Holm adjustment; see the result table for adjusted tests and simultaneous lower bounds. Synthetic results under the frozen 640-label cap; not real-data confirmation.”
