# Phase 10 and 10b ledger

Phase 10 adds benchmark families B, Bext and C. Phase 10b adds family D, sources with a known alternation mechanism. Both use the Phase 7 pipeline, shuffle control and orientation handling; the positivity rule is unchanged (two-state fit passes G1 and G2, a positive premium in some (T, B) cell, and the shuffle control in `run_phase5.eval_streams`, which allows at most 1 of 5 positive shuffles; every positive below has 0/5). Non-positive datasets are listed with the reason and are not added to the paper.

Records live in `results/attempts_phase10_shard{0..3}.jsonl`, `results/attempts_phase10_retry.jsonl` (a retry record supersedes a shard record whose status was `fetch failed`; the original failure is noted in the status column) and `results/attempts_phase10b.jsonl`. This file is generated by `scripts/paper4_continuation/rbdp/real_data/make_ledger_phase10.py`; do not edit by hand.
