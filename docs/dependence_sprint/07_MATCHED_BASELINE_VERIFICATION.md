## Update: Sethi et al. Algorithm 1 reproduced (binary chain) — `src/shiftlab/dep/sethi.py`, `scripts/dep_sprint/sethi_sanity.py`, `sethi_vs_oracle.py`
Reimplemented from the paper's pseudo-code (null set = {a(1-r0) <= r0 b}, convex 1-D inner problem; alpha-correctness is their Theorem 4.1, proof **not re-checked**). Sanity (500 iid paths, null mean 0.3): rejects 100% at true mean 0.9 / 0.6 / 0.45 (median stop 50 / 90 / 320 steps) and **0%** at the boundary 0.3 — behaves as specified.
On the lazy-resample chain (T=2000, 1000 paths, alpha=0.05, `sethi_vs_oracle.json`): size at the boundary 0.000 for every persistence; power **0.00** for eps = 0.05 and 0.10 at T*delta = 1, 20, 100, and 0.00 / 0.02 at T*delta = 500, against oracle ceilings of 0.02 / 0.18 / 0.48 / 0.98 (eps = 0.1). Reading: the test is alpha-correct and *asymptotically* optimal as alpha → 0; at alpha = 0.05 its threshold beta_t = log(1/alpha) + psi_t is dominated by the kernel-complexity term (about 18-21 nats at 1000 visits per state) while a persistent chain carries only ~T*delta*eps^2/(2 pi(1-pi)) ≈ 12 nats about the mean (T*delta = 500, eps = 0.1). The oracle ceiling is additionally unattainable because it knows the persistence, which a composite null does not. **Gate B's conclusion is therefore reinforced: the best published valid test for the fully observed marginal-null problem has no practical power in the persistent regime.**
