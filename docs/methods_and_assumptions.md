# DIVE methods and assumptions

This document describes the first implemented DIVE comparison: decision-loss proxying, prediction-powered monitoring, selective label acquisition, and bounded sequential evidence. The initial benchmark answers a narrow question: at matched pre-monitor label-query rates, how do uniform and adaptive query designs estimate and detect an increase in paired deployed-versus-reference decision cost?

## Estimand and information flow

For a frozen deployed policy `pi` and a prespecified reference policy `pi_ref`, the per-event contrast is

\[ Z_t = c(\pi(X_t),Y_t)-c(\pi_{ref}(X_t),Y_t), \qquad H_t=Z_t-\epsilon. \]

The monitoring null is `E[H_t | F_{t-1}] <= 0`, where `F_(t-1)` includes all prior covariates, decisions, propensities, query indicators, and labels that have arrived. At the current event the learner sees `X_t`, its fixed policy decisions, a proxy prediction `h_t=h(X_t)` fitted only with previously available outcomes, and a query probability `q_t` selected before seeing `Y_t`. If queried, the paired costs and label arrive immediately in this first simulation. The evaluator separately knows the synthetic conditional outcome probability and can compute exact expected policy costs; this oracle information is never passed to proxy, query, or monitor inputs.

Both policy costs are computed on the same observed outcome, so this benchmark studies paired full-information classification costs. It does not cover settings where taking one action changes the outcome or prevents observing the counterfactual action's cost.

### Population nulls versus finite-stream oracle flags

In earlier saved runs, `material_harm` was based on evaluator-average conditional cost over a particular finite covariate path and regime interval. The corrected metrics preserve that pathwise indicator in `sample_path_material_harm` and use `material_harm` for the alternative/onset classification. For the fixed source-threshold incumbent/reference policies, independent one-dimensional integration gives population excess cost `0.079295` for both stationary and benign-nuisance data, below the fixed `0.10` margin. The nuisance shift affects only unused coordinates. The shifted boundary-local and residual-variance regimes have population excess costs `0.378274` and `0.131882`, respectively, above the margin. Thus finite stream averages can exceed the margin by chance even under a population null; monitor false escalation must be counted against the population null, not by treating every such pathwise evaluator flag as a true alternative. Reproduce the independent calculation with `uv run python scripts/validate_dive_population_harm.py` and see `outputs/reports/dive_population_harm_validation.md`.

## Proxy and prediction-powered estimate

The first proxy is Ridge regression for `H_t`; a separate random forest predicts the held-out residual second moment. Fit rows are split chronologically before monitoring. Validation predictions diagnose RMSE and calibrate acquisition scores. Queried outcomes are passed to `DecisionLossProxy.observe` only after their estimator contribution has been formed. Online Ridge refits use only the historical fit sample and queried outcomes that have arrived. The residual-second-moment model is frozen in this initial experiment.

The estimate is

\[ \widetilde H_t=h_t+\frac{I_t}{q_t}(H_t-h_t), \]

where `I_t` is Bernoulli with the recorded predictable propensity `q_t`. Conditional on current covariates and pre-outcome information, randomization gives `E[tilde H_t | X_t, F_(t-1)] = H_t`, regardless of proxy misspecification, when `q_t>0` and the outcome is observed whenever `I_t=1`. The implementation rejects a non-null outcome argument on unqueried events to make this information boundary testable.

The input contrast is clipped to a known bound `M=max(false-negative cost, false-positive cost)+epsilon`; the proxy is clipped to the same interval. Prediction-powered methods use the fixed worst-case bound `M(2/q_min-1)` and direct inverse-propensity sampling uses `M/q_min`. These constants preserve the stated null `E[H_t | F_(t-1)]<=0`, even when current-feature-dependent propensities are used. A tighter event-specific bound depends on current covariates and would require a stronger pointwise conditional null or a separate proof; the current implementation does not use it. Small query floors therefore make the sequential process conservative.

## Query designs

The benchmark compares full feedback, uniform direct inverse-propensity estimates, uniform prediction-powered estimates, a PPRM-style adaptive-reliance analogue under uniform sampling, entropy/uncertainty sampling, residual-variance sampling, and a decision-value heuristic. In the unit-cost run, query score multipliers are calibrated on the validation slice to target the same expected query rate and are then held fixed. The adaptive policies use `sqrt(v_t)` for estimated residual second moment and `sqrt(v_t) exp(-|h_t|/tau)` for a heuristic that prioritizes uncertain cases near the material-harm boundary. These are working acquisition heuristics, not solutions to a proven optimal allocation problem.

An optional heterogeneous-cost experiment adds a known label tariff `k_t = 0.5 + 2 sigmoid(X_{t,d})`, visible before the query and bounded in `[0.5,2.5]`. All sparse-query designs calibrate on validation to the same expected spend `r * mean(k)`; out-of-time spend may drift when the feature distribution changes, and the budget remains expected rather than a realized cap. The added cost-aware variance rule uses

\[
q_t = \operatorname{clip}\!\left(\lambda\sqrt{\frac{\hat v_t}{k_t}},q_{min},q_{max}\right),
\]

with `lambda` calibrated to the expected-spend constraint. For known conditional residual second moment `v_t`, this is the clipped Lagrange solution to minimizing `E[(1/q_t-1)v_t]` subject to `E[k_t q_t]` being fixed. This is classical cost-constrained Neyman allocation. It grounds the implementation and supplies a stronger baseline; it does not establish a new contribution or optimize detection delay directly. Run the GPU comparison with `uv run shiftlab-dive --seeds 30 --n 3200 --device cuda --heterogeneous-label-costs --cost-stability-tolerance 0.05 --output outputs/cost_stabilized`.

The query module also includes a cost-neutral mixture. For a per-event spend target `b` and known cost `k_t`, its neutral branch is `q_0(k_t)=b/k_t`, feasible when it lies within `[q_min,q_max]` on the full supported cost range. It spends exactly `b` in conditional expectation at every event. Mixing it with any adaptive propensity `q_A` in `[q_min,q_max]`, `q_rho=(1-rho)q_0+rho*q_A`, gives

\[
\left|k_tq_\rho-b\right|
\le \rho\max\left(|k_{min}q_{min}-b|,|k_{max}q_{max}-b|\right)
\]

for every event with `k_t` in `[k_min,k_max]`; averaging preserves the same bound under any covariate distribution. For a requested tolerance `delta`, the implementation sets `rho=min(1, delta/D)` where `D` is the bound at `rho=1`, choosing the largest admissible adaptive weight. The helper checks feasibility and tests verify the algebraic bound. `cost_stabilized_proxy` integrates it into the heterogeneous-cost monitor. A 30-seed pilot verified the expected-spend bound in stationary, nuisance-shift and boundary-harm scenarios, but did not improve detection over uniform querying. This convex-mixture bound is elementary robustification, not a novelty claim.

An exploratory CUDA tolerance sweep (`outputs/cost_tolerance_grid_exploratory/reports/tolerance_grid.md`) compared `delta` values 0.01, 0.025, 0.05, and 0.1 on the same ten stream seeds per scenario. All 12 scenario/tolerance cells passed the expected-spend drift check. Under benign nuisance shift, stabilized sampling spent less than uniform (mean 351–373 versus 487) but had slightly higher stream-mean RMSE point estimates; paired 95% bootstrap intervals crossed zero at n=10. No stream in this small paired block triggered harm detection. This grid is exploratory, and its spend target is calibrated on validation rather than a matched realized-spend budget. The separate 30-seed `delta=0.05` pilot detected harm in 0/30 stabilized streams versus 5/30 uniform streams. These results do not establish that tolerance changes detection power; the next test should compare methods at a prespecified common realized-label or dollar budget.

## Common hard label-dollar budget

The hard-budget benchmark (`outputs/hard_budget_pilot_30/reports/hard_budget_comparison.md`) compares uniform, variance, decision-value, cost-variance, and cost-stabilized query policies under the same per-stream dollar cap. For seed `s`, the cap is `B = r * mean(validation_tariff) * N_monitor`, where `r` is the predeclared target rate. Each policy keeps positive predictable propensities on every processed event. Before opening the next event, the procedure stops if the remaining balance is below the known maximum tariff `C_max`; otherwise any query costs at most `C_max` and cannot exceed the remaining budget. Thus actual cumulative spend is bounded pathwise by `B`, while the number of labels and monitored events are random.

The e-process is frozen at this budget stopping time. Under the same bounded-increment conditional-mean null required by the fixed-horizon monitor, predictable query propensities, and the filtration that includes arrived labels and past spend, optional stopping preserves the false-alarm bound. The stopping rule deliberately checks the previous balance before the next event, so it does not select the monitored horizon based on the current covariate or evaluator outcome. This is a straightforward hard-cap wrapper around an e-process, not a novelty claim. The recorded sum of `q_t * tariff_t` along the realized stopping path is a predictable-spend compensator; it can exceed `B` pathwise and is not the actual spend. The hard cap applies to realized sampled tariff only.

The CUDA 30-seed pilot used `B≈360.70` per stream. Actual spend never exceeded its seed-specific cap (450 policy-stream rows, zero violations). All 30 boundary-harm onsets were reached. Under method-specific e-process bounds, uniform sampling detected 4/30 and the four adaptive policies detected 0/30; no false escalation was observed in the stationary or benign-nuisance rows. However, uniform always queries at 0.10 and therefore uses a tighter fixed increment bound than adaptive methods that can query at 0.05. A paired sensitivity rerun giving every method the common `q_min=0.05` bound yielded 0/30 detections for all policies, with all harmful onsets reached. The initial detection gap is sensitive to threshold conservatism and cannot be attributed to allocation alone. See the [bound sensitivity report](../outputs/hard_budget_pilot_30/reports/eprocess_bound_sensitivity.md).

Cost-stabilized sampling averaged 255 labels versus 233 for uniform at comparable spend in boundary harm, with paired RMSE difference `+0.0018` (95% seed-bootstrap CI `[-0.0059, 0.0083]`). Cost-variance Neyman averaged 246 labels but had higher stream-mean RMSE than uniform by `0.0201` (`[0.0050, 0.0348]`). In benign nuisance, only one of 30 streams met evaluator materiality, so harm power there is uninformative. All policies share random numbers, and the uniform hard-budget alarms match the full-monitor baseline through the stopping time: four earlier alarms remain, while one later full-monitor alarm is censored by budget stopping. These are descriptive pilot results, not evidence of a general allocation optimum; confirmation requires a predeclared common bound (or sharper valid eventwise construction), fresh seeds, and budgets selected for power.

A fresh 60-seed matched-bound study was then run under the locked [protocol](hard_budget_matched_bound_protocol.md), with 20% target spend, `q_min=0.10`, `q_max=0.80`, and a shared fixed e-process bound. Across 900 method-stream rows there were no cap violations, all 60 boundary-harm onsets were reached, and false escalations were 0/60 in both stationary and benign-nuisance population-null controls (exact 95% upper bound 0.060). Finite-stream oracle averages above the margin remain pathwise diagnostics and do not redefine these controls as alternatives. Cost-stabilized allocation detected 12/60 boundary-harm streams versus 8/60 for uniform; the paired difference was `+0.067` (95% seed-bootstrap CI `[0.000, 0.150]`), unadjusted for the four adaptive comparisons. Its RMSE was `0.0548` versus `0.0554` for uniform (paired difference `-0.0006`, CI `[-0.0082, 0.0068]`). It used about 44 more labels at similar spend (`$713` versus `$712`). This is a weak, non-confirmatory signal and does not establish an allocation advantage. The exact detection intervals, paired differences, and complete seed-level Parquet are recorded in `outputs/hard_budget_matched_qmin_010_replication_60/`.

The reliance analogue estimates a scalar from the historical covariance of the observed paired contrast and proxy prediction, divided by the variance of proxy predictions and the labeled-to-unlabeled ratio. It updates only after a uniformly queried label arrives and clips reliance to a configured finite interval. It tests adaptive proxy weighting in this stream setting; it does not reproduce PPRM's source-risk bound, batch construction, or empirical-Bernstein confidence sequence.

## Evidence-growth allocation (new exploratory method)

`evidence_growth_proxy` uses only pre-monitor fitted inputs to allocate the same expected query budget. For a fixed e-process bound `B`, stake mixture `(lambda_j,w_j)`, proxy `h(x)`, model probability `p_hat(y|x)`, and the two possible bounded paired contrasts `H_y(x)`, it maximizes the predicted stake-weighted log-wealth increment

\[
U_x(q)=(1-q)A_x+q\sum_{y\in\{0,1\}}\widehat p(y\mid x)
\sum_jw_j\log\left(1+\frac{\lambda_j}{B}\left[h(x)+\frac{H_y(x)-h(x)}q\right]\right),
\quad A_x=\sum_jw_j\log\left(1+\frac{\lambda_jh(x)}B\right),
\]

subject to `mean(k(x) q(x)) = target_rate * mean_validation(k)`, and `q_min <= q(x) <= q_max`. The program solves the clipped KKT condition `U'_x(q)=eta*k(x)` using bisection. For each outcome/stake term, writing `a=1+lambda_j h/B` and `b=lambda_j(H_y-h)/B`, the curvature of `q log(a+b/q)` is `-b^2/[q(aq+b)^2] <= 0`; therefore `U_x` is concave in `q` on the domain where all betting factors are positive. The dual solution is the global optimum for this **estimated conditional outcome model and the declared surrogate objective**.

The objective is the expected log wealth of a stake component drawn from the fixed stake mixture, not the exact expected log of the mixture e-value. The outcome probabilities are predicted by the pre-monitor classifier; the two potential paired contrasts are computed from learner-visible policy actions and the known cost matrix. The monitor labels do not tune the policy. Model misspecification can direct labels poorly. Predictable propensities and the existing worst-case PPI bound retain the same monitor validity assumptions, but the allocation objective provides no power guarantee and is not claimed as novel. The held-out comparison must determine whether this mechanism is useful. Reproduce with `uv run shiftlab-dive --device cuda --methods uniform_proxy decision_value_proxy evidence_growth_proxy --scenarios stationary benign_nuisance boundary_local_harm --seeds 30 --output outputs/evidence_growth_primary`.

In the fresh 30-seed exploratory run `outputs/evidence_growth_replication_30/`, the raw rule matched its 10% validation query rate but averaged 13.9% in benign-nuisance monitoring (335 labels per stream versus 236 for uniform); it detected 0/30 boundary-harm streams versus 1/30 for uniform. This run exposed out-of-distribution budget drift and no detection benefit, so the un-stabilized policy is not a matched-budget improvement. `evidence_growth_stabilized_proxy` shrinks the propensity toward uniform. For `q_A(x) in [q_min,q_max]`, `q_rho(x)=(1-rho)r+rho q_A(x)` and `rho=min(1,delta/max(r-q_min,q_max-r))` imply `|E[q_rho]-r|<=delta` under any feature distribution, assuming the adaptive policy remains within its bounds. This rate bound is a direct convex-mixture result.

The stabilized rule was evaluated on a separate 30-seed block with `delta=0.01`. Mean monitor propensity was 10.09% under benign nuisance and 10.00% under stationary and boundary harm. It detected 0/30 harmful streams versus 3/30 for uniform PPI; the paired detection-rate difference was -0.10 (95% seed-bootstrap interval `[-0.233, 0.000]`, unadjusted). Its paired stream-mean RMSE difference under boundary harm was -0.0031 (`[-0.0122, 0.0066]`), also inconclusive. There were no false escalations in 30 streams per null scenario for either method (each 95% Wilson upper endpoint 0.114). Given the small detection counts and the near-uniform mixture, the evidence-growth allocation has not shown a useful gain and should not be part of the primary claimed method on this benchmark. See `outputs/evidence_growth_stabilized_replication_30/reports/evidence_growth_paired_comparison.md` and `outputs/evidence_growth_replication_30/reports/evidence_growth_paired_comparison.md` for paired analyses. The decision-value heuristic also overspent in benign nuisance (350 versus 242 labels per stream in the stabilized block) without detection benefit.

## Validation-selected residual-variance allocation grid

The allocation grid varies expected monitor label rates over 0.05, 0.10, and 0.20 and score powers over 0, 0.25, 0.50, 0.75, and 1. For score power `p`, the predictable query rate has form `q_t = clip(lambda * vhat_t**p, q_min, q_max)`; `lambda` is calibrated on the pre-monitor validation slice. The search selects `p` by minimizing the fully labeled validation estimate of query-randomization variance, then evaluates every grid point and the selected member on a separate forward monitor period.

For fixed event outcomes and proxy values, Bernoulli query randomization gives

\[
\operatorname{Var}_I\!\left(h_t+\frac{I_t}{q_t}(H_t-h_t)\mid X_t,H_t,\mathcal F_{t-1}\right)
=\left(\frac{1}{q_t}-1\right)(H_t-h_t)^2.
\]

Replacing the squared residual by its conditional second moment `v(X_t)` and imposing an expected query budget `sum_t q_t = B`, minimizing the sum of these variances is equivalent to minimizing `sum_t v(X_t)/q_t`. The Lagrange condition is `q_t = sqrt(v(X_t)/lambda)`. With propensity floors and caps, the solution is clipped to those bounds. Thus score power 0.5 is the classical Neyman allocation for this variance objective; it is an established baseline, not a novelty claim. The validation grid is useful because `v` is estimated and bounds, finite samples, and proxy misspecification can change which exponent works out of time.

The budget is an expected rate calibrated on validation, not a hard realized label cap. Current-feature propensities remain known and predictable, and the e-process uses the global bound implied by the minimum propensity. Since propensities depend on current features, validity continues to target the unconditional conditional-mean null given prior history. The outer monitor labels never select the power. Reported grid performance is descriptive across independent seeds and does not imply that the selected exponent is uniformly optimal.

## Rate-stabilized Neyman allocation

The power grid exposed a failure mode: after a feature shift, the residual-score distribution can change and a validation-calibrated adaptive policy can spend far more than its target rate. The rate-stabilized variant first calibrates the Neyman propensity `q_N(X)` to mean `r` on validation, then uses `q_rho(X)=(1-rho)r+rho*q_N(X)`. If `q_N` is clipped to `[q_min,q_max]`, then for any deployment feature distribution,

\[
\left|\mathbb E_{deploy}[q_\rho(X)]-r\right|
\le \rho\max(r-q_{min},q_{max}-r).
\]

Given a prespecified tolerance `delta`, the implementation sets `rho=min(1, delta/max(r-q_min,q_max-r))`. The mixture keeps positive, predictable propensities; its guaranteed propensity floor is `(1-rho)r+rho*q_min`, and that floor is used for the fixed e-process increment bound. A validation-only search compares tolerances by estimated query-randomization variance, then evaluates the chosen tolerance and all grid points on forward monitor events. This is a bound on expected query-rate drift under arbitrary covariate shift, not a hard cap on realized label counts. The bound is an elementary consequence of convex mixing, so the method is a grounded robustness baseline rather than a novelty claim.

After a covariate shift, the realized query rate can differ from the calibration rate. Reports must show actual query counts and propensity ranges; they must not describe this as a hard total-label budget. A future fixed-budget design should explicitly stop, allocate by remaining budget, and account for the resulting predictable propensities.

## Sequential evidence

For fixed stakes `lambda` in `(0,1]`, each process multiplies wealth by `1+lambda*tilde H_t/B`, where `B` is a known absolute bound. The mixture over these stakes is an e-process under the conditional-mean null and the stated boundedness assumptions. A threshold of `1/alpha` controls the probability of ever crossing under that null. The separate start-time mixture averages processes started at prespecified stream positions; it does not repeatedly reset the test after inspecting outcomes. Its positions and weights must be fixed before monitoring.

The code reports empirical crossing frequencies only as a diagnostic. Its guarantee requires the conditional null for the filtration actually used, correct costs, predictable policy/query choices, valid positive propensities, immediate label availability as implemented, and the declared increment bound. Dependence, delayed/adaptively sampled labels, arbitrary policy changes, estimated propensities, and adaptive choice of stakes are not covered without additional theory. If a policy changes, the null's estimand and predictable filtration must be restated.

## Shadow candidate certificate component

`CandidatePromotionTest` is evaluated in a separate full-feedback simulation. Candidates carry a model identifier, parent version, last training event index, and position in the candidate sequence. On each fresh forward event, the test receives both incumbent and candidate costs and monitors `G_t = c(incumbent)-c(candidate)-k_switch` against the null `E[G_t | past] <= 0`. Candidate `i` receives `alpha_i=alpha_total/[i(i+1)]`; these levels sum to `alpha_total`, so a union bound covers an unbounded sequence of tests. The candidate must be frozen before evaluation. The experiment compares an early-data logistic recalibration with an incumbent snapshot. The exact-copy snapshot gives a pointwise no-benefit control outside the deliberately harmful policy-update scenario.

The experiment assumes both policies' costs can be evaluated on the same outcome. This holds for the synthetic cost matrix, but not generally when actions change outcomes; those settings need randomized or valid off-policy evaluation. The recalibrated candidate can encounter regime-varying gains, so its measured false-certification rate is descriptive unless the pointwise conditional null holds. Model-version persistence and operational rollback are not implemented.

### Forward-time candidate-grid experiment

`shiftlab-dive-promotion-grid` extends that two-candidate diagnostic into a frozen grid comparison. Each stream is split in chronological order into training, validation, shadow-monitor, and untouched deployment slices. The incumbent is a policy fixed before the stream; twelve logistic candidates are fitted on training data and span four regularization strengths and three threshold scales. One exact incumbent copy is included as a pointwise no-improvement control. Validation outcomes rank the frozen candidates before the monitor begins. The fixed validation order receives `alpha_i = alpha/[i(i+1)]`, so the total allocated level is at most `alpha` even though ordering uses validation data. Each candidate is tested on fresh shadow outcomes with the paired net-gain e-process, a fixed-horizon one-sided Azuma-Hoeffding test, and a fixed-horizon empirical-Bernstein test. The deployment slice compares never promote, unconditional validation selection, both fixed-horizon gates, and sequential certification.

For the sequential test, the tested increment is `G_t = c(incumbent)-c(candidate)-k_switch/H`, with the one-time switching charge amortized over the fixed deployment horizon `H`; the final deployment metric subtracts the full charge once. Certification is absorbing: it is recorded at the first `e_t >= 1/alpha_i` crossing and is not revoked if later e-values decline. The test assumes candidates and their order are frozen before shadow monitoring, complete paired outcomes are available immediately, and increments are conditionally bounded with a valid conditional-mean null.

The empirical-Bernstein gate tests the *average expected net gain over the fixed monitor horizon*, a different null from the sequential test's eventwise conditional-mean null. It maps bounded gains `G_t in [-B,B]` to `U_t=(G_t+B)/(2B) in [0,1]`. Let `s_n^2` be the unbiased sample variance and split candidate level `alpha_i` equally between variance estimation and the upper-tail bound: `delta_v=delta_m=alpha_i/2`. For independent observations, including non-identically distributed observations, the empirical variance bound gives `sqrt(v_bar) <= sqrt(s_n^2)+sqrt(2 log(1/delta_v)/(n-1))` with probability at least `1-delta_v`; `v_bar` is the average marginal variance. Bernstein's inequality then bounds `U_bar - E[U_bar]` by `sqrt(2 v_bar log(1/delta_m)/n)+log(1/delta_m)/(3n)`. The gate promotes only if the observed mean exceeds the null boundary `1/2` plus this radius. Capping `v_bar` at `1/4` uses the known variance maximum for `[0,1]`. This is an established empirical-Bernstein construction, not a new theorem; see [Maurer and Pontil (2009), Theorems 10 and 11](https://www.cs.mcgill.ca/~colt2009/papers/012.pdf). It is valid for the grid's independent synthetic monitor draws, even where a deterministic regime schedule makes their distributions differ over time. It is invalid under unmodeled serial dependence or feedback that couples outcomes across events. The base Hoeffding gate instead uses only boundedness and the conditional-mean null, so it remains the dependence-robust fixed-horizon comparator.

The candidate grid also compares the existing validation-rank alpha-spending rule with equal allocation over the finite grid and a validation-power weighted Bonferroni rule. The latter sets `alpha_i=alpha(0.1/K+0.9 softmax(z_i))`, where `K` is the number of candidates and `z_i=clip(max(0, mean(validation_gain_i)/SE(validation_gain_i)),0,5)`. If the validation standard error is zero, a positive validation gain receives score 5 and a nonpositive gain receives score 0. All weights are computed from validation only, normalized to sum to one, and frozen before monitor outcomes are observed. Conditional on validation, each candidate test retains its allocated level and the union bound controls the familywise error at `alpha`. The independent-pilot principle is established in weighted multiple testing, including [Ignatiadis et al. (2016)](https://www.nature.com/articles/nmeth.3885); this particular score and its combination with decision-harm promotion remain an exploratory baseline, not a novelty claim. The evaluation asks whether it improves power and downstream value over simple equal and rank allocations without weakening the stated error control.

### Repeated candidates with a pathwise label cap

`shiftlab-dive-budgeted-promotion` extends the frozen candidate family to a shared sparse-label monitor. The seven environments are the six registered decision-harm scenarios plus an all-exact-copy candidate-family null. Each stream has 13 candidate policies. Chronological training and validation slices determine candidate fitting, validation order, the query score, and candidate alpha weights; all are frozen before the monitor. Every candidate uses the same queried outcomes and a common pathwise label cap. When no label remains affordable, the stream stops before the next event. Outcomes not queried are available only to the synthetic evaluator.

The monitor compares direct inverse-propensity `I_t Z_t/q_t` with the prediction-powered correction `h_t + I_t(Z_t-h_t)/q_t`, where `Z_t` is incumbent cost minus candidate cost. Query propensities are predictable from current covariates and pre-monitor scores and have a positive lower bound. Under the conditional-mean null, this makes the corrected increment's conditional expectation equal the full-feedback contrast; a bounded betting process then gives an anytime-valid candidate test. Alpha weights are fixed on validation and sum to at most `alpha`, so the finite-family union bound applies conditional on the pilot data. The guarantee requires the stated bounded increments, an appropriate conditional-mean null, valid query randomization, and immediate observed labels. The hard cap is enforced pathwise but can censor the monitoring horizon. The test certifies mean shadow-period benefit after amortized switching cost; untouched future value is a separate synthetic score and can turn negative after a regime change. The exact-copy family checks implementation behavior but does not establish calibration by itself.

The 60-seed CUDA run (`outputs/budgeted_promotion_grid_ipw/`) contains 15,120 stream-level rows, 252 summary cells, 77 matched-seed contrasts (308 metric rows), and zero cap violations. Across all scenarios and query policies, neither estimator promoted at the 10% cap. At the 20% cap, prediction-powered monitoring also had zero promotions. Direct IPW under rank spending promoted 18.3–21.7% of boundary-local streams and 23.3–28.3% of recurring-regime streams; it promoted 21.7% under uniform querying in harmful adaptation, while variance and decision-value querying promoted 1.7% and 0%. There were no certificates in stationary, benign-nuisance, residual-variance, or exact-copy controls. These rates are descriptive with only 60 independent streams per cell. Paired bootstrap intervals are seed-level percentile intervals, unadjusted across 77 contrasts.

At the 20% cap, rank alpha spending had higher expected future net gain than equal allocation in boundary-local and recurring alternatives; the rank-minus-equal paired gain differences were 60.8 (95% CI 31.2–93.3) for boundary harm with decision-value queries and 78.0 (41.6–117.7) for recurring regimes. Decision-value versus uniform query differences were inconclusive in those two scenarios and negative in harmful adaptation. This run does not show a general active-acquisition advantage. Direct IPW's lower worst-case bound gives it more power here, but it is not evidence that IPW generally dominates prediction-powered monitoring: the two bounds are conservative worst-case choices, and the finite sample and many zero-promotion cells leave substantial opportunity cost. No method was selected from the evaluation grid. See the [paired report](../outputs/budgeted_promotion_grid_ipw/reports/budgeted_promotion_grid.md) and matched seed table.

### Predictable decision-local betting bounds

The hard-budget monitor supports `bound_mode="decision_local"`. For each frozen candidate `k` and event `t`, before the outcome arrives it computes the exact support bound of the estimator from the known policy actions, two possible binary outcomes, the current query propensity, the pre-monitor proxy, and the amortized switching charge. For direct IPW, this is `b_tk = max(|-s|, |z_0/q_t-s|, |z_1/q_t-s|)`. For prediction-powered monitoring, it is `max(|h_t-s|, |h_t+(z_0-h_t)/q_t-s|, |h_t+(z_1-h_t)/q_t-s|)`, where `s=k_switch/H` and `z_y` is incumbent cost minus candidate cost under outcome `y`. This can be smaller than the fixed worst-case bound when a candidate's action contrast is locally small.

The validity condition is stronger than the global-bound mode. Let `G_(t-1)` be prior history, reveal `X_t` before the query draw, and let `q_t` and `h_t` be measurable with respect to `(G_(t-1), X_t)`. Assume the frozen paired gain satisfies the pointwise null `E[Z_t-s | G_(t-1), X_t] <= 0`, and query selection is randomized independently of `Y_t` conditional on that information with `q_t>0`. Then both direct IPW and the prediction-powered correction have conditional expectation `E[Z_t-s | G_(t-1), X_t]`. Since `b_tk` is also predictable and the increment lies in `[-b_tk,b_tk]`, for any fixed stake `lambda` in `[0,1]`, `1 + lambda (estimate-s)/b_tk` is nonnegative and has conditional expectation at most one. A fixed mixture of such products is therefore an e-process; validation-frozen candidate levels summing to at most alpha plus a union bound control the finite family against this pointwise null.

If the null only states `E[Z_t-s | G_(t-1)] <= 0`, covariate-dependent normalization can reverse the sign after weighting by `1/b_tk`; the decision-local process is not justified by that weaker null. More fundamentally, rejecting the pointwise null only shows that some covariate contexts have positive conditional net gain. It does not certify the aggregate mean net benefit required to promote a candidate: positive and negative subgroup gains can cancel or reverse in expectation. The global-bound mode remains the conservative option for that average-gain target, subject to its predictable-query and boundedness assumptions. The candidate-grid run with decision-local bounds had no crossings in any of 15,120 records, despite local scales averaging only 6.9% of the corresponding global scale. Thus the one-candidate calibration signal did not transfer to this adaptation setting. Candidate-specific betting bounds, adaptive propensities, and hard stopping do not themselves create a novel theorem. [Waudby-Smith and Ramdas's predictable plug-in empirical-Bernstein confidence sequences](https://academic.oup.com/jrsssb/article/86/1/1/7043257) remain a critical next monitoring baseline. The exact-copy family is degenerate and cannot assess type-I error, so separate calibrations use nonzero paired-cost variation. A further mixed-sign calibration constructs two equally likely strata whose conditional candidate gains are +0.12 and -0.12 in cost units, giving exactly zero aggregate mean. Across 2,000 CUDA streams per cell, the global-bound process crossed in 1.2–2.1% of streams, while decision-local scaling crossed in 2.5–5.8%. At cost ratio 5 and a 30% cap, crossings were 41/2,000 (2.05%) globally and 115/2,000 (5.75%) locally; the local Wilson interval was 4.8–6.9%. This empirically exposes the estimand mismatch: local crossings can occur when aggregate expected net gain is zero. The proof-level issue is decisive; finite Monte Carlo rates are diagnostic. See `outputs/mixed_mean_null_local_bound/reports/mixed_mean_null_calibration.md` and reproduce with `uv run python scripts/calibrate_mixed_mean_null_local_bounds.py --streams 2000 --horizon 600 --seed 27102026 --device cuda --output outputs/mixed_mean_null_local_bound`.

The independent CUDA calibration has 2,000 streams per cell, horizon 600, a single fixed candidate, asymmetric cost scales `{1, 2, 5}`, and query caps `{10%, 20%, 30%}`. Under the nondegenerate pointwise null, the largest observed escalation rate was 2.2% (44/2,000) for the local scale and 2.3% (46/2,000) for the global scale; both remain below the nominal 5% level, and the corresponding Wilson intervals are in the report. Under cost ratio 5, 30% label cap, and outcome probability 0.56, local scaling crossed in 415/2,000 streams versus 280/2,000 for global scaling; the matched rate difference was +6.75 percentage points (paired 95% t interval +5.16 to +8.34). At a 20% cap and the same alternative, it was 278 versus 209 (+3.45 points, +2.00 to +4.90). When the cost ratio was 1, methods were identical. The 27 paired intervals are unadjusted, so these are exploratory gains concentrated in heterogeneous-cost settings, not a general superiority result. The full stream and paired data are in `outputs/decision_local_bound_calibration/`; reproduce or recompute paired analysis with `uv run python scripts/calibrate_decision_local_bounds.py --streams 2000 --horizon 600 --seed 26102026 --device cuda --output outputs/decision_local_bound_calibration` and append/rebuild paired metrics with `--analyze-existing`.

### Promotion timing under changing benefit

`shiftlab-dive-promotion-timing` compares the fixed-start bounded-mean e-process, an equally weighted three-start mixture, a fixed-horizon empirical-Bernstein gate, a fixed-horizon Hoeffding gate, and never promoting. It runs a single candidate per stream, so no candidate-family correction is needed. The generated benefit schedules are evaluator-only. Potential costs are independent Bernoulli variables across events, bounded in `[0,1]`; therefore both fixed-horizon gates apply to the average expected shadow gain even when the eventwise means change. The e-processes test the eventwise conditional-mean null and are valid under their bounded supermartingale condition. All rules see the same paired shadow costs. Sequential promotion starts on the event after a crossing; fixed-horizon decisions occur only after the shadow interval. The remaining potential outcomes are used only to score post-promotion value.

The benchmark is a synthetic timing diagnostic, not a method claim. It assumes complete paired potential costs and no action-dependent outcomes. In benefit reversal, an e-process may correctly reject the all-time nonpositive-gain null during an early positive phase, yet the candidate can have negative forward value after that phase ends. The fixed-horizon gates avoid most such promotions in this schedule because their estimand averages the whole shadow interval, but they incur the predeclared monitoring delay. Seed-level results and code are in `outputs/promotion_timing_v6/` and `src/shiftlab/dive/promotion_timing.py`.

### Two-phase persistence confirmation

`shiftlab-dive-persistence-grid` adds a fixed discovery phase and a disjoint persistence phase. For each phase `j`, the frozen candidate's bounded net-gain increments are passed to a level-`alpha` e-process. Promotion requires both phase processes to cross before their respective phase ends. The tested null is the union `H0 = H0_discovery ∪ H0_persistence`, where `H0_j` states that every event in phase `j` has nonpositive conditional expected net gain. Under `H0_discovery`, the conjunctive promotion event is contained in the discovery-process crossing event, whose probability is at most `alpha`; under `H0_persistence`, it is contained in the persistence-process crossing event, also at most `alpha`. Thus the intersection-union test controls promotion at `alpha` without dividing the level between the two phases. This argument does not require independence between the phase tests, but it does require their conditional-mean supermartingale assumptions and boundaries fixed before monitor outcomes. Candidate families still require candidate-level alpha allocation.

The CUDA grid compares discovery fractions 0.25, 0.50, and 0.75 with the existing gates over five schedules and 1,000 independent streams per schedule. Under benefit reversal, the 0.50 split promoted 6/1,000 (0.6%, Wilson 95% CI 0.3–1.3%) versus 997/1,000 for the full-start process; its mean oracle future net gain was −0.372 [−0.669, −0.075], compared with −30.131 [−30.841, −29.420] for full-start. This is a substantial reduction in harmful promotion, but never promoting had zero expected gain, so the persistence gate did not beat that fallback on this schedule. Under persistent benefit, the 0.50 split promoted 974/1,000 and gained 155.950 [153.885, 158.015], below full-start's 255.727 [254.309, 257.145]. Under late-onset benefit, the 0.75 split promoted only 42/1,000, versus 998/1,000 for the multi-start process; the fixed discovery phase misses many late changes. These results show the safety/opportunity-cost trade-off; they do not establish a useful new algorithm. All splits and baseline rows are in `outputs/persistence_promotion_grid/`.

### Switching-cost and reversal robustness grid

`shiftlab-dive-promotion-robustness` evaluates the same gates on matched potential-cost streams across one-time switching charges 0, 10, 30, and 60. Its six fixed schedules are no benefit, persistent benefit, and reversals at early/short, early/long, middle/long, and late/short settings. Reversal onset is a fraction of the shadow window; reversal duration is 20% or 55% of the full stream, with expected benefit returning to zero afterward. Switching cost is paid once after promotion and amortized over the deployment horizon in the monitor increments. This tests sensitivity to a prespecified charge; the grid does not estimate an optimal charge.

Across 1,000 CUDA streams per schedule, the no-benefit false-promotion rate for the full-start process decreased from 3.4% at zero switching charge to 0.2% at charge 60. Under the early long reversal at charge 0, full-start promoted 1,000/1,000 with mean oracle net value −18.01 (95% t CI −18.70 to −17.31); persistence splits promoted 7–8/1,000, while never-promote returned zero. The middle long reversal exposes a failure mode of early discovery: at charge 0, discovery fraction 0.25 promoted all streams, with mean net value 6.70 and 22.8% nonpositive future net outcomes, whereas fractions 0.50 and 0.75 promoted 7/1,000 and 4/1,000. That delayed confirmation also sacrifices persistent benefit: at charge 30, the 0.50 persistence gate promoted 61.4% and averaged 72.85 net value, versus 98.8% and 193.19 for full-start. At charge 60, these rates were 7.6% and 52.5%, with average values 6.39 and 71.97. In the late short reversal, fraction 0.75 promoted only 10/1,000 at zero charge, despite positive future value for faster gates. The complete 144-cell summary and seed-level Parquet are in `outputs/promotion_robustness_grid_corrected/`.

These are descriptive synthetic comparisons across a 192-cell grid; the reported cellwise confidence intervals are not multiplicity-adjusted. The results do not support a uniformly preferable discovery split or a new-algorithm claim. The persistence gate can screen an early transient only when the reversal arrives before confirmation, and it can still promote before a later reversal. Its delay also gives up measurable value under persistent and late-onset benefit. The benchmark assumes independent event noise, complete potential outcomes, and no action-dependent outcomes. It does not solve repeated-candidate alpha allocation, adaptive label budgets, delayed feedback, or real policy evaluation.

The last deployment slice is evaluative, not part of model or candidate selection. A certificate controls its stated shadow-period null; it cannot guarantee positive gain on a later regime that changes. `false_promotion_post_nongain` measures such a later reversal, not type-I error. Synthetic counterfactual costs are observed by construction; an application where the action affects outcomes needs randomized or valid off-policy evaluation.

## One-step intervention controller component

`InterventionController` takes expected one-step loss reductions and label, compute, and switching costs for the finite actions `continue`, `query`, `recalibrate`, `update`, `retrain`, `promote`, and `fallback`. It chooses the available action with the highest positive expected net value and otherwise continues. Promotion is unavailable until its separate statistical certificate is true; fallback is unavailable until an external authorization/gate is true. These hard gates are not traded against estimated utility. The forecasts are inputs and are not currently learned or calibrated by the benchmark, so the controller offers no regret or safety guarantee.

## Metrics and interpretation

The experiment keeps separate quantities for feature discrepancy (`feature_mmd_mean`), predictive uncertainty (used by one query rule), paired observed-cost estimation error, evaluator-known expected decision harm, alarm/delay, and imposed label-cost-adjusted expected excess cost. The latter is only a sensitivity analysis with a configurable synthetic label price; no intervention benefit is measured. False escalation is an alarm before the evaluator-known first material-harm index or any alarm in a no-material-harm stream. Detection and delay are counted only for material-harm streams.

Initial experiment limitations are immediate labels, one synthetic binary task, known common-outcome paired costs, a frozen deployed policy, simple linear proxy, no intervention, and a finite predeclared start-time mixture. Candidate testing and intervention selection exist as standalone components but are not integrated into this experiment. Results are Monte Carlo descriptions, not evidence of real-world utility or novelty.

### Predictable variance-adaptive betting baseline

`PredictableVarianceAdaptiveEProcess` uses a single predictable plug-in Kelly stake on globally normalized net-gain increments `R_t = X_t/B in [-1,1]`. Before event `t`, it sets `lambda_t = clip(max(0, m_hat_(t-1))/s2_hat_(t-1), 0, 0.5)`, where the running mean and second moment use a fixed four-observation prior (`0.05` and `0.25`). It updates wealth by `E_t = E_(t-1)(1+lambda_t R_t)`. Under the history-conditional average-gain null `E[X_t | F_(t-1)] <= 0`, any predictable `lambda_t in [0,1]` makes the factor nonnegative and its conditional expectation at most one. Thus the validity argument is immediate; the Kelly approximation only selects a stake for power. This is a standard predictable betting strategy, not a new theorem or novelty claim. It retains the global support bound, so it preserves the aggregate estimand that eventwise covariate normalization loses.

An initial paired CUDA grid used 2,000 streams in each of 27 cells, a 600-event horizon, hard label caps of 10%, 20%, or 30%, costs `{1, 2, 5}`, and an exactly zero aggregate mixed-sign null plus broad and high-cost-only positive alternatives. On the nine aggregate-null cells, fixed-mixture crossing rates ranged from 1.0% to 2.6% (mean 1.79%); the adaptive-stake rates ranged from 1.2% to 3.05% (mean 2.21%). Both were below 5% in this finite calibration. Across positive cells, adaptive crossing averaged 11.89% versus 11.77% for broad gains and 6.63% versus 6.07% when only the high-cost stratum benefited. Cellwise paired results were mixed, and intervals are unadjusted. This is not a demonstrated overall power improvement. The present plug-in Kelly rule is only a transparent baseline; the matched published PM-EB comparison follows below. See `outputs/predictable_stake_calibration/` and reproduce with `uv run python scripts/calibrate_predictable_variance_stakes.py --streams 2000 --horizon 600 --seed 28102026 --device cuda --output outputs/predictable_stake_calibration`.

### Matched published PM-EB comparison

The direct PM-EB comparison implements the predictable plug-in empirical-Bernstein (PM-EB) process of [Waudby-Smith and Ramdas (2024)](https://academic.oup.com/jrsssb/article/86/1/1/7043257) on the same globally bounded inverse-propensity gain. It maps `R_t=X_t/B in [-1,1]` to `Z_t=(R_t+1)/2 in [0,1]`, tests `E[Z_t | F_(t-1)] <= 1/2`, and uses log increment `lambda_t(Z_t-1/2)-4(Z_t-mu_hat_(t-1))^2 psi_E(lambda_t)`, with `psi_E(lambda)=(-log(1-lambda)-lambda)/4`. The stake schedule is `lambda_t=min(1/2, sqrt(2 log(2/alpha)/(sigma_hat^2_(t-1) t log(1+t)))`; the smoothed mean uses a half-count prior, and the variance schedule uses post-update residuals, as specified by the paper.

The upper-null extension follows directly from the one-step inequality `exp(lambda u-4u^2 psi_E(lambda)) <= 1+lambda u` for `u >= -1`. Write `a=mu_hat_(t-1)`, `m=1/2`, and `delta=E[Z_t | F_(t-1)]-m <= 0`. The conditional expectation of the process factor is at most `exp(v)(1+lambda*delta-v)`, where `v=lambda(a-m)`. This expression is maximized at `v=lambda*delta`, with maximum `exp(lambda*delta) <= 1`. Thus each predictable PM-EB factor is a nonnegative supermartingale factor under the eventwise history-conditional upper null, including non-identically distributed increments. This argument relies on one event-time update per stream, the common known support bound, positive randomized query propensity, immediate labels, and stopping only at event boundaries.

In the 27-cell CUDA grid with 2,000 paired streams per cell, fixed-mixture, plug-in Kelly, and PM-EB crossing rates averaged 1.76%, 2.03%, and 0.39% across the nine exact aggregate-null cells. On broad-positive alternatives they averaged 11.49%, 11.48%, and 5.19%; when only the high-cost group benefited, they averaged 6.13%, 6.63%, and 2.46%. PM-EB was conservative and less powerful for this inverse-propensity setting; Kelly was close to the fixed mixture on average and varied by cell. Intervals are unadjusted over the grid. These are descriptive results, not a winner selection or a novelty claim. The complete report, matched Parquet metrics, figure, and checksum manifest are in `outputs/predictable_betting_comparison/`; reproduce with `uv run python scripts/calibrate_predictable_variance_stakes.py --streams 2000 --horizon 600 --seed 29102026 --device cuda --output outputs/predictable_betting_comparison_reproduction`.
