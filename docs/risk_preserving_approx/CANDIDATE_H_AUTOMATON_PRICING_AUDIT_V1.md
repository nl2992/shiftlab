# Candidate H: finite-response-automaton pricing for causal-null cuts

**Status:** exact conditional reduction `PROVED`; compactness and novelty
`NOT ESTABLISHED`. **Decision:** do not implement as a lead. Retain as a
possible exact pricing baseline only if a future candidate supplies an a priori
bound on active-response automata and reachable pricing beliefs.

## Proposed mechanism

In policy-column generation, a restricted master carries a finite set
`I={1,...,m}` of pure causal-null responses. Encode each response as a
deterministic finite-state transducer `M_i=(Q_i,q_i^0,delta_i,p_i)`: after each
event it updates its state from the null-visible learner request and generated
outcome, and on a query it chooses endpoint probability `p_i(q) in {0,1/2}`.
For master multipliers `lambda_i >= 0`, pricing minimizes

    C_alt(pi) + sum_i lambda_i R_i(pi).

The pricing state is a belief over a hidden root mode: the alternative HMM with
its regime and pending outcomes, or one active response machine with its
transducer state and pending outcomes. The public learner state also carries
event time, remaining requests and deployment. Labels enter the learner belief
only at registered release times. Promotion adds the weighted risk reward and,
under the alternative mode, hands off to the exact continuation DP.

## Exact conditional theorem

Assume finite horizon, finite action/label alphabets, finite active set `I`, and
finite deterministic response machines supplied exactly. For each fixed
multiplier vector, the belief-state Bellman recursion returns an exact
minimum reduced-cost learner policy. Conditional on the hidden mode and its
current state, transition and reward laws are Markov; the learner observes only
released labels, so its posterior over the disjoint hidden-state union is
sufficient. Request fees are charged at request time; queued outcomes are
generated by the selected hidden mode and revealed only at due events. Promotion
terminates the risk reward and retains the alternative continuation cost.
Thus the recursion preserves the pricing objective exactly.

If the response machines have `K=sum_i |Q_i|` total controller states and `P`
possible pending-label queues, the hidden-state representation has at most
`O((1+K)P)` states before adding the two alternative regimes. With one request
per event and fixed delay `d`, `P <= sum_{j=0}^{min(B,d)} binom(d,j) 2^j` because
only the previous `d` request slots can still be pending. This is not a bound on
the number `M` of reachable learner beliefs. Exact finite-horizon DP needs
`O(M * |A| * |O| * N)` arithmetic operations and `O(M*N)` dense belief storage,
where `N=O((1+K)P)`; these counts exclude rational bit complexity. `M` can equal
the full public-history count, and `K` can itself be as large as the response
history tree. In Candidate G's T=10 IID-root graph, a one-state IID response
mode still yielded 4,867 reachable beliefs, exactly the 4,867 public-history
states. The theorem therefore gives exactness conditional on the supplied
representation, but no improvement in `T,B,d` or active-set size for the
unrestricted causal-null family.

At a completed column-generation/double-oracle solve, exact pricing plus exact
full-null separation recovers the original finite game optimum. At an early
stop, a restricted-master dual is a valid lower bound only when its LP dual
feasibility and pricing reduced-cost residual are certified; an independently
verified policy gives a feasible upper bound. These are standard finite-game
and column-generation guarantees. They do not give a useful gap until pricing
state size and end-to-end work are bounded.

## Counterexample and state-size obstacle

The public-history counterexample in
`CANDIDATE_B_PRICING_STATE_COUNTEREXAMPLE_V1.md` has two event-3 histories with
the same time, budget, deployment, physical belief and empty pending queue but
different next-response probabilities under one fixed active null. A response
machine distinguishes them with separate automaton states, so this state fixes
that particular belief-only error.

But arbitrary history-adaptive nulls may need one continuation state for many
public transcripts. `CANDIDATE_C_RESPONSE_QUOTIENT_LOWER_BOUND_V1.md` gives a
family with `binom(T-2,q)` pairwise distinguishable transcripts for a
strategy-independent quotient. That proposition is not a lower bound on every
null-specific machine, but it rules out a universal compact response quotient.
Even when `K` is small, distinct observation histories can induce distinct
beliefs, so automaton minimization alone does not prove `M` is small.

## Source match and G1 decision

This is an exact specialization of established constrained-POMDP policy-column
generation and sequence-form double-oracle methods. Walraven and Spaan already
optimize over policy columns using unconstrained POMDP subproblems
([JAIR 2018](https://www.jair.org/index.php/jair/article/view/11216));
Bošanský et al. give sequence-form double-oracle methods for extensive-form
games ([JAIR 2014](https://doi.org/10.1613/jair.4477)). Robust finite-state
controller synthesis with exact verification is also established
([Cubuktepe et al., AAAI 2021](https://ojs.aaai.org/index.php/AAAI/article/view/17401)).
The ShiftLab-specific part is delayed-outcome bookkeeping and alternative
continuation. No irreducible theorem, compactness guarantee, or end-to-end
resource advantage remains.

The prior causal-cut screen materialized the same learner and null trees and
was slower than the exact solver on `T=5,6`; its `T=7` run stopped at the cut
limit. It did not test automaton-factorized pricing, but weakens the case for
another implementation without a state-count theorem. Its artifact did not
save individual response vectors, so automata cannot be retrospectively
minimized without a new run.

**Decision:** close Candidate H as a method lead. Do not rerun the prior cut
cells merely to retally automaton sizes. Reopen only if a structural assumption
already in the target formulation bounds both `K` and `M` below the learner
sequence form and yields a nonvacuous end-to-end comparison. No code, seeds,
synthetic outcomes, real data or holdout was used for this audit.
