# Integrated Q1–Q3 null calibration: archive arithmetic and provenance (partial W01/W04/W08)

`audit_integrated_null_calibration.py` verified the protocol, stream-metrics, and cell-summary hashes in the `integrated_null_calibration_v2` manifest and recomputed all four cells from the 4,355 archived attempted streams. Every cell has 1,000 eligible seeds and zero recorded errors. With one-sided confidence error 0.05/4, the exact zero-count binomial upper bound is `1-(0.0125)^(1/1000) = 0.004372439564671...`, below each stage alpha (Q1 .02, Q2/Q3 .015). All stored per-cell values match within 6e−17. No path exceeds 640 labels. Q2 has 1,089 attempts, 1,062 Q1 triggers, and 1,000 selected eligible candidates; none promotes. Q3 has 1,266 attempts, 1,000 promoted eligible candidates, and no rollback among them. The Q3 stored oracle radius is 0.0959705 from its declared 100,000 draws and delta 1e−8; eligible lower bounds are at least 0.2578003, above the `−0.05/800` cutoff. The registered synthetic diagnostic gate is reproduced from the archive.

This is conditional on the *registered eligibility populations*: Q2 counts selected candidates after Q1 triggering whose evaluator null flag is true, and Q3 counts beneficial promoted candidates whose independent-oracle lower bound clears the population null cutoff. Zero errors in these populations do not establish error rates for arbitrary candidates, other generator laws, or a complete composed theorem. The Q2 pointwise-null construction and Q3 oracle evaluation are claims about the generator and archived implementation; this audit has not independently regenerated their paths or proved their conditional-null premises.

The historical `verification.json` reports a successful source/hash check and replay of all 1,266 Q3 attempted streams. That replay was **not rerun** here. The v1 and v2 calibration directories have byte-identical `stream_metrics.parquet`, `cell_summary.csv`, and `verification.json`, but their manifests have different creation times and different SHA-256 hashes for `integrated_pipeline.py` (`da164...` versus `e47ae...`). Byte identity alone cannot distinguish deterministic rerunning from copied outputs. The v2 manifest's runner hash does not match the current tree and its exact bytes were not found among visible reachable path objects, unreachable Git blobs, or 20 active worktrees; the synthetic generator hash matches the dirty main checkout but not the clean audit tree. The protocol and integrated runner first appear in visible Git commit `32c5cfd` (2026-10-27 06:43:52 UTC), after the v2 manifest's recorded 2026-10-26 12:06:49 UTC time. Thus a fresh full source-matched replay and a pre-run Git freeze are unproven from available local artifacts. This does not negate the stored diagnostic counts or the historical verifier receipt; it limits this audit's independent provenance claim.
