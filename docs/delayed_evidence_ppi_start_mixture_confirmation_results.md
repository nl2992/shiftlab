# Delayed PPI fixed-start mixture: disjoint Markov-scale confirmation results

**Confirmation gate: PASS.** The frozen paired-shadow comparison completed on 300 fresh seed clusters (seeds 20322000–20322299), after the independent Markov-scale null calibration passed. It tested the fixed equal-weight eight-start mixture against the full-stream predictable-bound e-process under the same evidence-directed acquisition path.

Across the three equally weighted harm onsets, the start mixture detected 218/900 cases (**24.2%**) versus 169/900 (**18.8%**) for the full-stream monitor. The mean paired gain, averaged within each seed cluster before averaging across seeds, was **+5.44 percentage points** (seed-cluster percentile-bootstrap 95% interval [+3.78, +7.33]). There were 50 mixture-only and one full-stream-only detections. Both monitors used exactly **196.436 labels per seed-onset case on average**; each paired query-schedule SHA-256, label count, and event count matched. Three candidate alarms occurred before their harm onsets. All caps held, all labels resolved, and all registered events were processed once.

The late-onset absolute detection rate is still low. Event delays among detected streams were not uniformly shorter for the mixture. The result supports a modest power increase at matched acquisition in this registered persistent-scale synthetic design; it does not show general superiority, a safer deployment action, robustness to persistent sign dependence or informative delays, or performance on real data. The start mixture is a standard convex combination of e-processes and is not claimed as novel.
