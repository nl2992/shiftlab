# Delayed feedback with evidence-directed PPI: development results

**Decision:** the grid identifies `evidence_a0p025_p0p5_eventwise` as a candidate for independent null calibration. This is a development signal only; it is not a validated performance claim, and no new-algorithm or novelty claim is supported.

The frozen CUDA grid ran 30 independent streams per scenario across 11 methods, for 990 method-stream rows. Synthetic tensors were generated on the NVIDIA GeForce RTX 4060 Laptop GPU. Each arm shared its stream outcomes, query uniforms and independent delays with the other methods for that seed, and all arms had the same pathwise cap of 480 requested labels. The full audit found 990/990 unique keys, all expected seeds, methods and scenarios, zero cap violations, zero pending labels, and identical registered/updated event counts. The source hash in the manifest matches the executed module. Metrics, paired contrasts, configuration and runtime are in [`outputs/delayed_evidence_directed_ppi_grid_30/`](../outputs/delayed_evidence_directed_ppi_grid_30/); the frozen design is [`delayed_evidence_directed_ppi_grid_protocol.md`](delayed_evidence_directed_ppi_grid_protocol.md).

On the boundary-harm alternative, the leading low-activation curves each alarmed after onset on 3/30 streams (10%); uniform querying alarmed on 0/30. The preselected screen candidate `evidence_a0p025_p0p5_eventwise` used a mean 153.47 labels, compared with 472.20 for uniform, a paired difference of **−318.73 labels** (descriptive paired bootstrap 95% interval **[−335.30, −299.16]**). It completed 2,359.5 events on average, versus 2,378.3 for uniform. Its mean event-time detection delay among the three detections was 786.7 events after onset. The candidate-minus-uniform detection difference was **+10 percentage points**, with an unadjusted descriptive paired bootstrap interval **[0, +20.08] percentage points**; all three candidate alarms were discordant wins, but this small sample does not establish a power gain.

The same candidate had 0/30 alarms in both stationary and benign-variance controls. A one-sided 95% exact upper limit for 0/30 is about 9.5%, so this grid cannot establish the nominal 5% false-alarm rate. Another curve, `evidence_a0p05_p0p5_eventwise`, alarmed once in each control and once before onset in the harm scenario; this is a reminder that the urgency grid cannot be selected by alternative power alone. Uniform querying often reached the 480-label cap and stopped before the end of the 2,400-event target stream; the adaptive policies generally used fewer labels and processed more events, so comparisons must retain both label counts and completed horizon.

The paired PPI increment and its predictable event-specific bound were applied only when each queried label arrived and the contiguous event prefix advanced. The simulation is consistent with the intended delayed-feedback implementation, but its low-count observed alarm rates do not replace a statistical calibration argument or a high-replication calibration. The rule also depends on the event-history conditional-mean null, outcome-independent query randomization conditional on that history, correct propensities, a frozen source-trained proxy and policy pair, and eventual label resolution. Delay-dependent power and real decision utility remain unmeasured.

**Next gate:** freeze `evidence_a0p025_p0p5_eventwise` before examining fresh seeds, calibrate it and uniform on both null controls with simultaneous one-sided exact binomial limits, then run a disjoint harm confirmation only if calibration passes. No figure was generated.
