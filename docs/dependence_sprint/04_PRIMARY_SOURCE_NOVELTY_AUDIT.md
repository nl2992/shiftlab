## Reductions examined
1. **Fully observed Markov loss stream (the lazy chain of Gate B is exactly this).** The marginal null {P : stationary mean <= r0} is a prescribed set of transition matrices; Sethi et al. Theorem 4.1 gives an alpha-correct test. Their expected stopping time scales with mixing, **consistent with Gate B's oracle ceiling** (nothing can beat it at slow mixing). → the narrow inference problem for *fully observed* finite-state loss chains is **KNOWN**. I did not re-implement their test; alpha-correctness is taken from their theorem, proof not independently checked.
2. **Marginal null with a known mixing envelope** via Paulin-type concentration + a stitching / union bound over time gives a time-uniform interval whose width scales like sqrt(tau_mix log(t)/t). This is a standard composition (**implementation work, not new methodology**); and it is vacuous in the persistent regimes by Gate B.
3. **Conditional null** (the existing e-process monitors): classical martingale methodology, **KNOWN**.
## Exact novelty delta (the only candidate)
Time-uniform, finite-sample type-I control for the stationary-risk null when the loss is a bounded *noisy function of a hidden regime chain* (hidden-Markov), with selectively queried and delayed labels. Sethi et al. list the hidden-Markov case as open. Strongest plausible reduction: treat the observed loss alone as a (non-Markov) process and use an mixing-envelope concentration with union bound — which already yields a valid but vacuous-in-the-regime-of-interest test; **Gate B shows no test, valid or not, can have useful power there**. So the delta is mathematically real but its content is a *negative/obstruction* result plus a vacuous upper bound, and the elementary obstruction (Theorem B1) is very likely folklore.
