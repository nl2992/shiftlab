# Matched monitor power diagnostic: results

This fresh-seed development study compares the existing fixed bounded-mean mixture with predictable variance-adaptive and predictable plug-in empirical-Bernstein (PM-EB) gates. All monitors receive the same prediction-powered increments, global bound, queried labels, hard-budget stopping path, and alpha. It uses 30 seeds per scenario, a 20% dollar cap, three query policies, and four scenarios. The preregistered design is in [`monitor_power_diagnostic_protocol.md`](monitor_power_diagnostic_protocol.md).

The full report, event-level metrics, summary CSV, figure, and checksums are in [`outputs/monitor_power_diagnostic_30/reports/monitor_power_diagnostic.md`](../outputs/monitor_power_diagnostic_30/reports/monitor_power_diagnostic.md), [`outputs/monitor_power_diagnostic_30/metrics/hard_budget_comparison.parquet`](../outputs/monitor_power_diagnostic_30/metrics/hard_budget_comparison.parquet), [`outputs/monitor_power_diagnostic_30/metrics/monitor_comparison.csv`](../outputs/monitor_power_diagnostic_30/metrics/monitor_comparison.csv), and [`outputs/monitor_power_diagnostic_30/figures/monitor_power_comparison.png`](../outputs/monitor_power_diagnostic_30/figures/monitor_power_comparison.png).

## Findings

- **No monitor detected harm.** For fixed mixture, predictable variance, and PM-EB, there were 0/30 detections in both boundary-local harm and recurring regimes under each of the three query policies. Every one of the 180 harmful stream-policy cases reached its known harm onset before budget stopping. Detection delay is therefore undefined, not censored.
- **No control escalations were observed.** Each monitor had 0/30 false escalations in stationary and benign-nuisance cells. The 95% Wilson upper endpoint is 11.4%, so these 30-stream cells cannot establish a 5% false-escalation rate.
- **The adaptive gates did not improve on the fixed mixture in this block.** There were no paired discordant detections for either comparator versus fixed mixture; the exact McNemar p-value is 1 where defined. This is a no-signal result, not evidence of equivalence.
- **Monitor choice did not affect acquisition or resource use.** By construction, each monitor processes the same evidence sequence for a given query-policy/seed pair. Mean spend was about $710–$721 under the nominal $720 cap. Exact mixture-growth acquisition processed about 70.6% of boundary-harm events and 53.7% of recurring-regime events on average, but all corresponding onsets were reached.

The unchanged failure across three valid betting rules makes the fixed global bound a more useful next diagnostic than adding more stake schedules. In this cost matrix the bound is 198.9 because `M=5.1` and `q_min=0.05`. The next experiment will use uniform querying at rate 0.20 and the same streams to compare the valid bound induced by `q_min=0.20` with the `q_min=0.05` bound. Uniform query probabilities are unchanged by this comparison, so it isolates bound sensitivity while preserving the aggregate history-conditional null. This is still development work; a positive result would require separate null calibration and independent confirmation.

No new algorithm is supported by this diagnostic. The predictable variance and PM-EB processes are established methods. Keep them as baselines and do not describe them as ShiftLab contributions.
