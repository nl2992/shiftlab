## Existing method families in the repository

The component inventory above records the core candidates for the unified study. The repository also contains these reusable families; each needs a frozen, source-hashed reference configuration before a unified comparison:

- Monitoring: direct paired-cost fixed-stake e-process; started and horizon mixtures; predictable Kelly and empirical-Bernstein variants; CUSUM and feature MMD diagnostics; predictive-risk PPI/proxy monitors; full-feedback and inverse-propensity estimators.
- Acquisition: uniform, evidence-directed, residual-variance/Neyman, cost-variance, robust-active-inference adaptation, fixed and adaptive propensity floors, eventwise and delayed acquisition, and hard request caps.
- Candidate choice: pooled candidate rank; nested/context-volume rank; Target-Scout; eventwise and Markov/temporal scout variants; fixed-split promotion.
- Intervention: continue, always/conditional promotion, shadow promotion, rollback, stratified rollback, periodic retraining, triggered retraining, one-step cost-aware controller, and closed-loop resource/cost grids.
- Data and task support: synthetic known-truth generators; Folktables, gas sensor, EIA, OPSD, NOAA, Monash, Criteo Attribution and CRSP pipelines, with source-specific coverage and chronology caveats in [`real_data_inventory.md`](real_data_inventory.md).
- Criteo Attribution suitability: aggregate-only maturity audit of the pinned 16,468,027-row release found 3.31% label maturity by the last impression under the assumed 30-day rule. This supports excluding it from informative within-stream monitoring and retaining it only for retrospective or extended-follow-up stress tests; actual publisher release times remain unknown. See [`criteo_maturity_v2`](../../outputs/shiftguard_unified/real_data_development/criteo_maturity_v2/).

This list does **not** claim that every family has passed a statistical calibration or that all variants are mutually compatible. In particular, multiplying marginally valid monitors after adaptively selecting a policy, choosing a context after inspecting outcomes, or composing promotion and rollback can invalidate the advertised joint error control unless the alpha budget and conditional nulls cover the entire sequence.
