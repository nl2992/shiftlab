**Reductions that would defeat novelty claims for H2c:** (a) a PPI-increment betting test with a predictive-model-guided bet size is a special case of "betting on predictions"-style constructions with a side-information bet; (b) choosing the bet for one statistic from a correlated statistic is a mixture/side-information device; (c) nominal-risk uncertainty by α-splitting is in the PR line. I cannot confirm that any of these papers contains H2c's exact construction, nor that none does. **Novelty verdict for H2c: unresolved, leaning composition.**
