# Pre-analysis interpretation audit

Written while the first screen is running. This does not change its frozen grid,
primary metrics or survival rule. No partial ranking has been used to select a
candidate. The following limitations must accompany the completed screen report.

## Q2 endpoint and alternative definitions

The shared world list was designed around Q1 risk/cost deterioration, not around
Q2 candidate superiority. `harm_without_accuracy` raises disclosed decision costs
without reversing the label law; it does not make the opposite predictor superior.
`transient_challenger` creates a time-varying ranking, not persistent superiority.
Thus certification-by-horizon over the registered twelve "alternative" worlds is
an exploratory ranking statistic only. A higher value can include undesirable
certifications and cannot be called higher certification power. Apply the frozen
survival rule as written, retain mandatory controls, and separately show each
world's paired superiority contract and nonimprovement diagnostic. The next Q2
protocol must specify null/alternative worlds directly from its paired estimand,
freeze the target (conditional versus running mean), and calibrate false promotion
before power comparisons. Do not silently relabel this screen's metric as power.

The existing instantaneous conditional-benefit-at-certification diagnostic does
not prove a violation of a running-mean null. A candidate can have historical
average advantage and current disadvantage. Both should be reported explicitly;
the distinction motivates the intended separation between evidence and current
economic value but is not itself a new discovery.

## Cross-family metric averaging

G4 has a different normalized return loss from the classification families.
Pooled raw means implement the preregistered ranking but should not be interpreted
as a universal utility scale. Always show within-family paired differences and
per-scenario results alongside the pooled exploratory ranking. Rescaling costs
after outcomes to favor a candidate is prohibited. A later multi-family primary
endpoint needs a specified weighting/normalization before held-out evaluation.

## Null calibration and family coverage

The current source Hoeffding allowance is an IID reference bound. It does not
establish G3/G4 source-risk coverage. G3/G4 also need explicit conditional-null
analysis or empirical whole-world calibration. The current global fixed-bet PPE
construction can preserve a specified null under predictable query randomization,
but merely running a stationary world does not show that its intended conditional
null is true at the source threshold. Empirical null checks must be tied to the
actual declared null and finite-horizon familywise event.

None of WATCH, original PPRM, exact SMCS, original CAMS, PAI or Balanced Active
Inference is reproduced by the current screen. Several composition adapters are
local heuristics. The draft generic-shift comparators are not yet included in any
registered performance batch. The required source audit and matched-comparator
coverage remain outstanding regardless of the screen ranking.

## Research-stage completion boundary

The 540 screen configurations are genuine controlled development experiments,
but have one seed per family/scenario, one severity, one horizon, one budget and
one stale proxy. They are not adequate for uncertainty, broad robustness,
hyperparameter fairness, calibration, final confirmation or methodological novelty.
The later mandatory full-archive failure synthesis cannot be reduced to a ranking
of these 540 configurations. It must include subsequent matched baseline runs,
negative/invalid records, tuned candidates and independent development evidence.
