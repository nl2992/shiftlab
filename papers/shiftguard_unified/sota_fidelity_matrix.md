# State-of-the-art fidelity matrix

**Audit status:** working evidence map, updated 2026-10-26. This matrix distinguishes published results from ShiftLab implementations and planned comparisons. A citation is not evidence that we have reproduced a method. Full reproduction claims require a paper-to-code protocol, source hash, matched data/feedback, and an independently checked result manifest.

## Common comparison boundary

The target for the unified study is the expected cost contrast between a deployed policy and a declared reference policy, with event time separated from feature availability, decision time, label request, label arrival, and model update. The current synthetic runners often reveal full counterfactual outcomes to the evaluator; only the queried outcome and covariates may reach the learner. This is a useful controlled benchmark, but it is not interchangeable with contextual-bandit feedback, where only the chosen action's reward is observed. For every comparator below, we must either implement the published estimand and feedback model faithfully or label the ShiftLab version as an adaptation and avoid transferring its original guarantee.

### Q1 comparator update — Timans et al. (2026-10-26)

The direct conditional bounded-risk monitor in Timans et al., [*On Continuous Monitoring of Risk Violations under Unknown Shift*](https://proceedings.mlr.press/v286/timans25a.html), is now included as a source-pinned matched comparator. Its eventwise null maps exactly to the fixed paired decision-cost null after an affine transformation to `[0,1]`, with immediate full feedback and one prespecified policy pair. Independent replay of the official `approx_grapa` and `grapa` implementations matched log wealth to maximum absolute error `0` and `1.86e-7`, respectively. In the registered CUDA run (1,000 seeds per null control; 300 per alternative), each method had 0–2 false escalations per 1,000 null streams per control, and no Holm-adjusted paired alternative comparison was significant. All three methods detected every boundary-local, recurring-regime, and harmful-adaptation stream; all had low residual-variance detection (8–11/300). The result does not establish a ShiftLab advantage over the existing bounded-risk method. Together with Schirmer et al.'s adaptive-model predictive-risk monitor and prior cost-aware switching work, it requires any remaining Q1 contribution to be stated more narrowly and demonstrated against candidate-promotion baselines. Protocol, results, and independently checked outputs: [`Timans protocol`](timans_unknown_shift_paired_cost_protocol_v1.md), [`report`](../../outputs/shiftguard_unified/sota_reproductions/timans_unknown_shift_paired_cost_v1/report.md), [`verifier`](../../scripts/verify_timans_risk_monitor_paired_cost.py).

### Q2 matched finite-policy and candidate-gate comparison — 2026-10-26

A second frozen comparison evaluated official MOPE's preselected candidate-versus-logger gate alongside Molitor OPI's finite-class policy identification and matched fixed-horizon Hoeffding controls. On 1,000 all-tied null streams, MOPE promoted 11 (1.10%, exact 95% CI 0.55%–1.96%) and produced three empty confidence paths (0.30%, 0.06%–0.87%); a hash-matched replay confirmed the empty-path event times. On 300 alternatives with a +0.15 candidate gain, MOPE promoted 279 (93.0%, 89.50%–95.62%) after 114.04 labels on average, versus 92 (30.67%, 25.50%–36.22%) for the fixed-horizon gate using 200 labels. OPI and the fixed-horizon class selector produced no singleton in this 200-event alternative. These are different estimands and are not a head-to-head ranking. The result is a bounded, stationary synthetic check; it neither closes the real-data gate nor supports novelty for sequential OPE certification. See [`matched results`](opi_mope_matched_results_v1.md), [`frozen protocol`](opi_mope_matched_protocol_v1.md), and the [verified output](../../outputs/shiftguard_unified/sota_reproductions/molitor_mope_matched_v1/report.md).
