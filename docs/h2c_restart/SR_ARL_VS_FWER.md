# Shiryaev–Roberts: ARL versus finite-horizon error
- **ARL.** For the e-detector R_t = (1 + R_{t−1}) f_t with E[f_t | F_{t−1}] ≤ 1, E_{H0}[R_t] ≤ t, and the SR stopping time τ = inf{t : R_t ≥ 1/α} satisfies a lower bound E_{H0}[τ] ≥ 1/α (the e-detector framework of Shin–Ramdas–Rinaldo; source text not opened in this session, the statement is the standard one and should be re-checked against the paper). This does **not** bound P(τ ≤ T): with α = .05 the guaranteed average run length is only 20 steps, while the horizon here is 2000.
- **Finite horizon.** P_{H0}(τ ≤ T) ≤ α needs the mixture construction (doc VALID_RESTART_MIXTURE) or, equivalently for uniform weights, the SR threshold T/α.
- **Consequence.** The repository's earlier `sr_cost_tight` is an SR recursion with an *empirical* threshold (the 95th percentile of the horizon-maximum on a null stream). That targets a finite-horizon error on that null stream only (and was found not to transfer across configurations); it has neither guarantee. SR-1 at 1/α has an ARL guarantee and a very high finite-horizon false-alarm rate; SR-1 at T/α has the finite-horizon guarantee. The comparisons below keep these labels.
