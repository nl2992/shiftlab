# Regol, Schwinn, Sprague, Coates, Markovich, When to Retrain a Machine Learning Model
ICML 2025, PMLR 267 (regol25a). PDF (mlresearch GitHub mirror) extracted; Sec 3 setting, Sec 3.2 (Prop 3.1), Sec 4.1-4.2 (UPF) read; experiments and appendix skimmed.
Facts: objective C(pi) = sum e_t * loss + c_t * retrain; offline model/data history; forecasts the performance matrix pe_{i,j} with Beta-distributed predictions conditioned on features and time (UPF = Uncertainty-Performance Forecaster); retrain via a quantile of predicted cost (95% quantile target); Prop 3.1 upper-bounds the number of optimal retrains using a gap constant L. Baselines: CARA (Mahadevan & Mathioudakis 2024), ADWIN, FHDDM, KSWIN. Labels assumed available in the datasets (no label budget, no delay, no certified safety, no hard cap). Appendix proofs beyond the A.4 statement not read.
