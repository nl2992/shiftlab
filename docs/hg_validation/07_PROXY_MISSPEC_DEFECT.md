# 07. Proxy-misspecification null test: INVALID DESIGN (recorded, no conclusion drawn)
`scripts/sota_search/stress_proxy_null.py` scaled the nonlinear term by k ∈ {1, 3, 6} with no shift and compared alarms against the **G1 nominal risks**. Because the misspecified model's true risk is itself above those nominal values (stream Brier .175 / .238 / .287), the "null" is violated by construction: alarms (up to 1.0) are true detections of excess risk over a wrong baseline, not false alarms. The result file `outputs/hg_validation/07_PROXY_MISSPEC.json` is kept as a record of an implementation/design defect (status `implementation_defect`), and **must not be cited as evidence about validity**.
Correct design (not yet run): set the nominal risk r0 to the stream's own source-period risk for each k (a pre-shift calibration segment), then measure false alarms with no shift. `source_moments` currently hard-codes G1/G2 constants, so it needs a parameter override first.
