# 08 Development and adversarial tests
Code commit at start: `8552911`; sprint branch `research/shiftlab-dependence-gates-2026-10-31`. Inputs: `gate_ab.py`, `gate_b_oracle.py`, `lrv_transfer.py` and outputs. All synthetic; seeds 2026 / 11 / 77.
Adversarial families used: persistent hidden regime (delta 0.5 to 0.001), conditional-null-respecting ARCH-like dependence, iid. Results are tabulated in 02, 03 and 06. Key adversarial outcomes: (i) no violation of the stated conditional null by any monitor (UCB <= 0.044 over 2000 paths on iid and on conditional-mean-exact dependent streams); (ii) every monitor, and the heuristic repair, fails the marginal null under persistence — as it must, by Theorem B1; (iii) the oracle ceiling shows the failure is information-limited, not a tuning issue.
No development data were used to select a method (none was selected). Caveats: Monte-Carlo sizes are supporting checks only; 6000-path oracle estimates carry about +-0.01 standard error.
