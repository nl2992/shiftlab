# Valid restart mixture (reference construction; not claimed novel)
Let f_t ≥ 0 with E[f_t | F_{t−1}] ≤ 1 under H0 (here f_t = 1 + λ_t X^c_t, λ_t predictable, X^c_t the cost increment, 1 + λX ≥ 0.5), and predetermined weights w_t ≥ 0 with Σ_{t=0}^{T−1} w_t = 1. Define S_t = (S_{t−1} + w_t) f_t, S_{−1} = 0, and M_t = S_t + Σ_{j>t} w_j.
**Claim (PROVED).** M is a nonnegative supermartingale with M_{−1} = 1 ≥ ..., hence P_{H0}(max_{t<T} M_t ≥ 1/α) ≤ α. *Proof.* S_{t−1} + w_t is F_{t−1}-measurable, so E[S_t | F_{t−1}] ≤ S_{t−1} + w_t, and E[M_t | F_{t−1}] ≤ S_{t−1} + w_t + Σ_{j>t} w_j = M_{t−1}. M_{−1} = Σ w_j = 1; Ville's inequality gives the bound. ∎ Equivalent view: M_t is the w-mixture of the e-processes "start at j" (Π_{s=j}^t f_s), with unallocated capital retained.
**Link to SR.** Uniform w = 1/T gives S_t = R_t / T where R_t = (1 + R_{t−1}) f_t is the Shiryaev–Roberts statistic; so the finite-horizon-valid uniform-restart rule is SR with threshold ≈ T/α (minus the retained tail), not 1/α.
**Delayed releases.** PROVED for fixed delay when the factors are indexed in release order with F the release filtration (factor f_s is revealed at s + d, its bet λ_s is fixed from labels released by s). For random independent delay, factors released out of order give a valid mixture only if the weighted-sum recursion is applied in release order and the weights are indexed by *release* time; not proved or simulated here, so no claim is made. Outcome-dependent delay: no claim.
**Exact finite-support check** (`scripts/sota_search/restart_exact_test.py`, `outputs/h2c_restart/exact_restart_test.json`): T = 7, binary increments with E[X] = 0 exactly, history-dependent predictable bet, weights (.4, .1×6): exact P(sup M ≥ 20) = 0.00098 ≤ 0.05; the largest conditional drift E[M_t | history] − M_{t−1} is 1.8e−15 (zero up to rounding).
**Not covered:** restart-specific bets (each restart uses data since its own start) are also valid (mixture of e-processes) but were not implemented; Brier-guided time-varying capital allocation (R2) needs its own self-financing proof and is not claimed.
