**FCG novelty (reconciled with the decision):** the *scheme* is prior art. Bošanský et al. (read pp. 829–831)
restrict sequences and add best responses, and frame this as constraint/column generation. Krale et al. supply
the best-response oracle. The application to a two-law chance-constrained causal game is not itself shown to be
published. That is an application delta, not a method delta, and it does not support novelty wording beyond
"problem-specific algorithm". This is provisional pending a full read of Bošanský et al. §§4–6.
